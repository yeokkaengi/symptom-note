# 시연 순서

준비: `Pleos_Connect_v2.1.0` AVD, AVD Extended controls → Microphone → "Virtual microphone uses host audio input" 켜기, 증상노트 설치(README 참고), Virtual Console 열어 두기.

| # | 하는 일 | 화면에서 보이는 것 |
|---|---|---|
| 0 | (선택) 설정 → **시연 데이터 불러오기** | 노란 띠 "시연 데이터가 포함되어 있어요". 지난 5일치 평소 주행 + '브레이크 끼익' 증상 |
| 1 | Virtual Console 기어 **P** → 홈에서 **기록 시작** | "● 기록 중 (직전 10초 보관)", 알림 "증상노트 기록 중" |
| 2 | 홈의 **주행 중 기록 화면** → 화면 오른쪽 끝 창 막대를 왼쪽으로 끌어 **내비와 반반 분할** | 한쪽은 내비, 한쪽은 노란 큰 버튼 "방금 소리 기록" |
| 3 | Virtual Console: 기어 **D**, 가속해서 시속 20~40km, **브레이크** | 주차 화면은 시스템이 가리지만 큰 버튼 화면은 그대로 사용 가능 |
| 4 | 브레이크를 밟는 순간 소리(호스트 마이크로 끼익 소리 재생)를 내고 **큰 버튼** 누름. 2~3번 반복 | 버튼이 "기록 중"(0.25초 안), 저장 뒤 음성 "기록했어요" |
| 5 | 정차 → 기어 **P** → 홈 → **기록 목록**에서 방금 기록들을 골라 **증상으로 묶기**(예: 브레이크 끼익) | 증상 화면의 **공통 조건**: "시속 20~40km, 브레이크 중 — N회 중 N회 (평소 주행에서는 이 조건이 X%)" |
| 6 | 증상 화면 **자동 포착 켜기** | "켜짐 · (규칙)" |
| 7 | 다시 D → 같은 조건(시속 20~40km에서 브레이크) | 소리·화면 변화 없이 조용히 저장. 홈의 "자동 포착: HH:mm:ss … 저장" |
| 8 | P → 기록 목록 | 새 기록에 **자동** 표시 |
| 9 | 증상 화면 → **정비소 리포트** → **PDF로 저장** | 한 장 리포트, `Download/SymptomNote/report_….pdf` |
| 10 | 증상 화면 → **오늘 수리 완료로 기록** | 수리 후 확인 영역이 생김 |
| 11 | 다시 D → 같은 조건 몇 번 통과(자동 포착) → P | "수리 후 같은 조건 N회 통과 · 기록 M개 · 수리 전 특징 대역(…kHz)이 평균 ±dB (참고 지표)", 수리 전·후 나란히 재생 |

시간이 없으면 0번(시연 데이터)만 불러와 5·9·11번 화면을 바로 보여 줄 수 있습니다:
"차가운 날(바깥 10도 이하), 시속 20~40km, 브레이크 중 — 4회 중 4회 (평소 주행에서는 이 조건이 2%)",
"수리 후 같은 조건 12회 통과 · 기록 2개(자동 2개) · 수리 전 특징 대역(1~2kHz)이 평균 -19dB (참고 지표)".

참고
- 에뮬레이터의 바깥 온도는 25°C로 고정되어 있어, 실제 주행으로 만든 증상에는 "차가운 날" 조건이 나오지 않습니다.
- 평소 주행 기록이 30초 미만이면 기준률을 계산하지 않습니다(화면에 안내). 3번에서 1분 이상 달려 주세요.
- 녹음 중에는 글레오 음성 호출이 동작하지 않습니다(`docs/platform-findings.md`). 글레오 시연은 기록을 끈 상태에서 "증상노트에서 최근 증상 알려줘".
- 창문 점검(홈 → 창문 점검)은 실차 전제 기능입니다. 흐름만 보여 줍니다.
